# poster

A simple landing page demo for Codex.

## Running the page locally

You can open the site directly in your browser without any build steps:

1. Commit or stash any local changes you want to keep.
2. From the project root, open `index.html` in your browser (for example, double-click the file in your file manager or run `open index.html` on macOS, `xdg-open index.html` on Linux, or `start index.html` on Windows).

If you prefer to serve the page via a local web server, any static file server will work, such as:

```bash
npx serve .
# or
python -m http.server
```

Then visit the displayed `http://localhost` address in your browser.

## Committing changes

To capture your edits in git, stage and commit them:

```bash
git add .
git commit -m "Describe your changes"
```

After committing, you can continue iterating locally or push the commit to your remote repository when ready.
